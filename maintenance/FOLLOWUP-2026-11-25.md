Use trained human review for ambiguous regulatory implications and clinical conclusions; an optional Anthropic draft is not publishable evidence. No model key is needed for routine maintenance. Optional private drafts require `ANTHROPIC_API_KEY` and an explicit budget. At $3/M input and $15/M output tokens for [Claude Sonnet 4.6](https://platform.claude.com/docs/en/models/sonnet-4-6/overview), 1,500 input + 250 output tokens is about US$0.00825 per draft; actual prompts, retries and billing can differ. `SEMANTIC_SCHOLAR_API_KEY` is optional for source access; `SIGNALEX_API_KEY` is required for protected production API checks.
